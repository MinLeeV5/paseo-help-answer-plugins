# 验收记录

环境：Paseo daemon 0.12.0 / 0.13.0-beta.1，Node.js 22.22.0。实际桌面窗口为 0.13.0-beta.1。

v0.1.0 发布前复验（2026-10-23）：依赖已通过 `npm ci` 按锁文件重新安装，TypeScript 严格类型检查、29 项单元测试和 29 项 Chromium 模拟输入区验收全部通过。另已通过无 node_modules 的干净源码安装检查，隔离临时主机中插件状态为 running，检查后已停止并清理该主机。真实主机生成与通知验证沿用下方记录；原生窗口逐项点击验收仍未完成。

v0.1.1 发布前复验（2026-10-23）：最低要求改为 `>=0.12.0`，开发 SDK 锁定 0.12.0，补齐旧版没有插件翻译接口及图标组件的兼容处理。类型检查、39 项单元测试、40 项 Chromium 模拟输入区验收通过；Paseo 0.12.0 与 0.13.0-beta.1 的隔离源码安装均通过。Tab 修复会在离开 Agent 输入区后使旧候选失效，过滤旧缓存与迟到 RPC，保留原生草稿及仍可见的分屏。实际 Paseo 桌面已验证从显示 3 个真实候选的 Agent 切换到 Diff Tab 后建议消失，切回原 Agent 后旧建议不再恢复。v0.1.1 固定标签的安装验证在创建并推送标签后执行。

v0.1.2 发布前复验（2026-10-24）：生成改为复用源会话的 workspace，只归档辅助 Agent 和服务会话。基于 0.12.0 SDK 的类型检查、45 项单元测试和 40 项 Chromium 模拟输入区验收通过；Paseo 0.12.0 与 0.13.0-beta.1 的干净源码安装均为 running。真实 codex/gpt-6-luna 调用返回合格候选，辅助 Agent 和服务会话的 workspace 与源会话一致且均已归档；源 Agent 与 workspace 保留，工作区可见性不变。普通会话完成通知被观察到，辅助任务通知为 0。固定标签安装在推送 v0.1.2 后、公开 Release 前复核。
