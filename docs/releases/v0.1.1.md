# v0.1.1 — Tab 隔离修复与 Paseo 0.12 兼容

修复切换 Agent / Tab 后仍显示旧回复建议的问题。候选只在对应 Agent 的当前查看过程中有效，离开后失效，切回不会恢复旧候选。

## 修复

- **切换 Tab 后清除旧建议**：离开 Agent 输入区时收起候选并清除选中状态；缓存与迟到的生成结果不会让旧建议重新出现。
- **重新生成后再显示**：新一轮 Agent 成功回复，或在命令中心选择「生成回复建议」后，可显示新候选。
- **保留草稿与分屏独立性**：已填入原生输入框的文字继续保留；分屏中仍可见的 Agent 各自保留建议。同一 Agent 仍在另一窗格显示时，其建议保留。
- **完善桌面输入区识别**：处理隐藏、复用和身份冲突的输入区，并兼容 Paseo 按钮外层的 `display: contents` 布局，避免将候选绑定到其他 Agent。
- **支持 Paseo 0.12.0 及以上版本**：最低要求调整为 `>=0.12.0`，开发 SDK 同步以 0.12.0 为兼容基线；补齐旧版语言接口适配，保留中文、英文和跟随应用语言设置。

## 文档

- 默认 [OVERVIEW.md](https://github.com/MinLeeV5/paseo-help-answer-plugins/blob/v0.1.1/OVERVIEW.md) 改为英文，新增[简体中文译文](https://github.com/MinLeeV5/paseo-help-answer-plugins/blob/v0.1.1/OVERVIEW.zh-CN.md)。
- 补充自动生成默认行为、设置、模型用量、发送给 Provider 的上下文范围及桌面端限制，两种语言均说明 Tab 隔离规则。

## 安装与升级

要求 Paseo 0.12.0 及以上桌面端（`>=0.12.0`）。已验证 0.12.0 与 0.13.0-beta.1 的插件安装；实际桌面 Tab 切换验收使用 0.13.0-beta.1。目标主机需启用插件、支持后台工作区，并已登录可用的 Provider。

首次安装：

    paseo plugin install https://github.com/MinLeeV5/paseo-help-answer-plugins.git --ref v0.1.1
    paseo plugin ls help-answer

已从同一 GitHub 仓库安装：

    paseo plugin update help-answer --ref v0.1.1
    paseo plugin ls help-answer

确认插件启用且状态为 `running`。等待新一轮成功回复，或从命令中心选择「生成回复建议」（Generate reply suggestions）。点击候选只填入原生输入框，由用户编辑后自行发送；模型生成计入所用 Provider 的正常用量。

## 验证情况

- 基于 0.12.0 SDK 的 TypeScript 严格类型检查、39 项单元测试及 40 项 Chromium 模拟输入区验收通过。
- 在 Paseo 0.12.0 与 0.13.0-beta.1 的独立临时主机中，无 node_modules 的源码安装通过，插件状态为 `running`。
- 实际 Paseo 桌面验证：显示真实候选后切换到 Diff Tab，建议消失；切回原 Agent 后旧建议不恢复，未发送会话消息。

完整范围见[验收记录](https://github.com/MinLeeV5/paseo-help-answer-plugins/blob/v0.1.1/docs/verification.md)。

## 已知限制

- 保持 Pre-release；原生输入框接入依赖桌面 DOM 适配，Paseo 更新后可能需要适配。
- 浏览器交互验收使用模拟 Composer；实际桌面已验证本次 Tab 切换流程，其他原生窗口交互尚未逐项验收。
- 在 Paseo 0.12 中切换应用语言后，设置导航标题和命令名称需重新加载插件才会更新；建议区域与设置内容自动跟随。新版 Paseo 使用实时翻译接口。
- 后台辅助任务归档后仍保留普通历史；原生 iOS / Android 暂不支持，未接入 Jev。
