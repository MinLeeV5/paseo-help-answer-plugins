# v0.1.0 — Paseo 回复建议

首个桌面端预发布版本。Agent 完整回复后，提供几个可点击的候选回答；点击短文案按钮，即可将完整内容填入 Paseo 原生输入框，编辑后自行发送。

## 首发功能

- **自动生成候选**：仅在 Agent 成功完成回复后生成，默认 3 条，数量可配置为 2～5 条。
- **短按钮直接填入**：点击候选后填入完整内容并聚焦输入框，保留已有草稿；重复点击不重复追加，切换候选时保留后续补充。
- **按需显示**：没有候选、正在生成、生成失败或等待下一轮回复时隐藏建议区域；发送确认后收起旧候选。
- **手动生成与换一组**：可从命令中心选择「生成回复建议」，有候选时可点击「换一组」。
- **复用主机模型配置**：读取 Paseo 元数据模型配置，使用已有 Provider 登录；支持指定 `provider/model`，无需额外填写 API Key。
- **中英文与提示词设置**：界面默认跟随 Paseo，也可固定中文或 English；回复语言独立设置。内置提示词只读展示、可复制，支持附加生成要求，并可配置上下文轮数与超时。
- **后台生成隔离**：辅助任务不进入当前用户 Agent 的子 Agent 列表，不产生额外的 Agent Finish 提醒；普通对话的完成提醒保留。辅助任务与工作区在结束后归档。

## 安装

要求 Paseo 桌面端 `>=0.13.0-beta.1 <0.14.0`；实际验证的宿主版本为 `0.13.0-beta.1`。目标主机需启用插件、支持后台工作区，并已登录可用的 Provider。

安装本次固定版本：

    paseo plugin install https://github.com/MinLeeV5/paseo-help-answer-plugins.git --ref v0.1.0
    paseo plugin ls help-answer

确认插件状态为 `running`，等待下一轮 Agent 成功完成回复；已有对话可通过命令中心的「生成回复建议」（Generate reply suggestions）手动生成。

已从同一 GitHub 仓库安装的用户，也可切换到本次版本：

    paseo plugin update help-answer --ref v0.1.0

点击候选只会填入输入框，由用户通过 Paseo 原生发送按钮或 Enter 提交。模型调用计入所用 Provider 的正常用量。

## 验证情况

- TypeScript 严格类型检查通过。
- 29 项单元测试、29 项 Chromium 模拟输入区验收通过。
- 已通过真实主机验证模型生成、后台隔离、归档和辅助任务通知抑制。

完整结果见[验收记录](https://github.com/MinLeeV5/paseo-help-answer-plugins/blob/v0.1.0/docs/verification.md)。

## 已知限制

- 原生输入框填入与发送确认依赖桌面 DOM 适配层，宿主升级后可能需要适配。
- 截图及浏览器交互测试来自模拟 Composer；Paseo 原生窗口逐项点击验收尚未完成。
- 后台任务归档后仍保留普通历史，在后台工作区或归档记录中可能看到。
- 当前不支持原生 iOS / Android，未接入 Jev。
