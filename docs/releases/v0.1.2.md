# v0.1.2 — 复用当前会话工作区

回复建议现在直接复用当前会话的 workspace 创建辅助 Agent，不再创建独立后台工作区、固定的 `generator` 项目或专用生成目录。

## 变更

- 辅助生成 Agent 和专用服务会话都位于当前会话的 workspace，不挂到用户 Agent 的子 Agent 列表。
- 完成、失败、超时或取消后只归档辅助 Agent 和服务会话，保留用户 Agent 与 workspace。取消后迟到的 Agent 创建结果也会归档。
- 辅助任务识别按插件标签和专用名称处理，不会把同一 workspace 中的其他普通会话当成生成任务。
- 保留辅助任务完成通知抑制、请求合并、候选缓存与模型配置。没有 workspace 时跳过生成；已有 workspace 不可用时返回错误，不新建替代工作区。

## 安装与升级

需要 Paseo 桌面端 `>=0.12.0`、已启用插件，以及已登录的可用 Provider。

首次安装：

    paseo plugin install https://github.com/MinLeeV5/paseo-help-answer-plugins.git --ref v0.1.2

从同一 GitHub 仓库安装的用户可更新：

    paseo plugin update help-answer --ref v0.1.2
    paseo plugin ls help-answer

## 验证

- 基于 Paseo 0.12.0 SDK 的严格类型检查、45 项单元测试与 40 项 Chromium 模拟输入区验收。
- Paseo 0.12.0 与 0.13.0-beta.1 的无开发依赖源码安装和固定 Git 标签安装。
- 真实模型验收：辅助 Agent 复用源 workspace 并归档，源 Agent 与 workspace 保留、可见性不变，普通会话有完成通知，辅助任务完成通知为 0。

完整结果见[验收记录](https://github.com/MinLeeV5/paseo-help-answer-plugins/blob/v0.1.2/docs/verification.md)。

## 使用说明

辅助 Agent 沿用当前 workspace 的可见性和项目环境，可能出现在会话列表及归档历史中。升级不会删除旧版本已经创建的 `generator` 项目或历史记录。

原生输入框接入仍依赖桌面 DOM；本次浏览器验收使用模拟 Composer，实际桌面 Tab 切换验收沿用 v0.1.1。原生 iOS / Android 暂不支持。
